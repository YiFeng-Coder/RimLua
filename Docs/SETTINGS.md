# RimLua 设置说明

打开方式：游戏内 **选项 → 模组设置 → RimLua**。

设置页按功能分组，支持滚动；修改后约 **0.6 秒自动保存**，底部也有“保存设置 / 恢复默认设置”按钮。

---

## 1. 常用操作

| 按钮 | 作用 |
| --- | --- |
| 打开 Lua 控制台 | 打开 REPL，可执行 Lua、查看脚本、reload、API dump、统计 |
| 生成 API dump | 写入 `<Config>/RimLua/api-dump.md` |
| 打开配置目录 | 用资源管理器打开 `<Config>` |
| 重新运行冒烟测试 | 通过控制台队列在主线程重新跑冒烟（结果覆盖 smoke-report.txt） |

---

## 2. 脚本

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 启用本地脚本 | 开 | 是否加载 `<Config>/RimLua/scripts/*.lua` |
| 自动热加载 | 开 | 文件保存后 250 ms 去抖、下一帧重载 |
| 启动时运行冒烟测试 | 开 | 开发诊断用；正式游玩可关 |
| 目录 | — | 显示实际本地脚本路径 |

> 子模组自带的脚本不在此目录；见教程 §7 的 `WhenReady + LoadFileNow` 模式。

---

## 3. 执行预算

| 选项 | 默认 | 范围 | 说明 |
| --- | --- | --- | --- |
| 每片指令数 | 5000 | 100–100000 | 协程每执行多少条 VM 指令让出一次；越大越省调度、越大延迟越高 |
| 单次脚本墙钟预算 | 50 ms | 1–60000 | 单次脚本最多执行多久，超时中止并丢弃协程 |

---

## 4. 第三方 API

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 启用耗时预算/告警 | 开 | 关闭后只统计，不强制预算/告警 |
| 单次调用预算 | 10 ms | 超过则返回 Lua 错误并计入违规 |
| 慢调用告警 | 2 ms | 超过写 Player.log（每个 API 最多 3 次） |
| 重置 API 调用统计 | — | 清空 calls/failures/budget 统计 |

下方会显示：被调用过的 API 数量、总调用次数、预算违规次数。

> 同步 C# 调用无法中途抢占，预算只能“事后判定失败”；请让 API 保持短小。

---

## 5. 持久化

| 选项 | 默认 | 范围 | 说明 |
| --- | --- | --- | --- |
| state 总上限 | 256 KB | 16–4096 | 所有脚本 state JSON 合计上限；超出则保存空状态并报错 |

显示当前保存的脚本状态条数。state 随存档保存/恢复、热重载保留、开新游戏清空。

---

## 6. 运行状态

只读信息：运行时是否初始化、已加载脚本数、第三方 API 数、冒烟报告路径、API dump 路径、文档路径。

---

## 7. 设置保存

- 修改后 0.6 秒自动 `WriteSettings()`；
- “保存设置”立即写入；
- “恢复默认设置”会重置所有选项并写回；
- 设置保存在 RimWorld 的 ModSettings 文件中，与存档无关。
